接口调试

向当前服务发送请求，查看状态码、耗时和响应体。请求会带上 x-request-id，便于把响应与 page-visit.log 关联起来。调试配置与页面访问记录保存在进程内存中，重启服务后会清空。

调试配置可以按「写入 → 查询 → 读取并清空」试一遍。

带 version 写入时，版本不一致会返回 409，并给出 currentVersion。

页面访问默认最多保留 100 个 tab，超限淘汰最久没有打开的记录。

请求头里的 x-request-id 合法时原样返回，否则由服务端生成新的 uuid。

可选。x-request-id 需为 8–64 位字母、数字、下划线或连字符；留空时由服务端生成。

Ctrl / ⌘ + Enter

选择左侧接口，或改好请求后发送。
