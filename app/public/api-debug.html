接口调试

向当前服务发送请求，查看状态码、耗时、响应大小和响应体。左侧可以搜索接口、点 ☆ 收藏常用接口，请求也可以一键复制为 cURL 接到脚本里。请求会带上 x-request-id，便于把响应与 page-visit.log 关联起来。调试配置与页面访问记录保存在进程内存中，重启服务后会清空。

调试配置可以按「写入 → 查询 → 读取并清空」试一遍。

带 version 写入时，版本不一致或格式非法会返回 409，并给出 currentVersion。

页面访问默认最多保留 100 个 tab，超限淘汰最久没有打开的记录；被淘汰的 tab 重新打开后会从 1 重新计数。

请求头里的 x-request-id 合法时原样返回，否则由服务端生成新的 uuid。

点开左侧接口会覆盖当前表单；发送记录只保留最近 20 条。

路径支持直接带查询参数，例如 /api/page-visit?tabId=tab-2；只允许请求当前服务。当前接口只注册了 GET / POST / DELETE，PUT / PATCH 仅用于临时探测。

可选。x-request-id 需为 8–64 位字母、数字、下划线或连字符；留空时由服务端生成。值可以是字符串、数字或布尔值。

Ctrl / ⌘ + Enter

选择左侧接口，或改好请求后发送。
